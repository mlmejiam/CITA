# Cita Linda

Frontend responsive de reservas para profesionales independientes, construido con Angular 21 y componentes standalone.

## Ejecutar

```bash
npm install
npm start
```

Abre `http://localhost:4200`.

## Compilar

```bash
npm run build
```

Incluye dashboard, agenda, disponibilidad semanal, servicios, validación de adelantos Yape y planes Básico/Premium. Los datos son demostrativos y están listos para conectarse a una API.
